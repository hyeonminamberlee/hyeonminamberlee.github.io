# Naturalistic Decision-Making in a Minecraft-Based Environment

<img src="/assets/img/project_minecraft.png" alt="Minecraft-based naturalistic decision-making task" class="project-full-img">

## Overview

This project examines how nicotine abstinence is associated with value-guided exploration and exploitation in a Minecraft-based 3D decision-making environment.

By combining choice behavior, reward trajectories, movement trajectories, and view dynamics with cost-sensitive reinforcement-learning models, this work aims to identify behavioral and computational signatures that are difficult to observe in standard 2D laboratory tasks.

## Research Question

How does nicotine abstinence alter value-guided decision-making, exploration, movement, and cost sensitivity in a naturalistic task environment?

## Approach

- Designed and implemented a Minecraft-based 3D multi-armed bandit task
- Built reproducible pipelines for choice behavior, reward trajectories, movement trajectories, and view dynamics
- Adapted cost-sensitive reinforcement-learning models to examine how movement costs shape exploration and exploitation
- Compared behavioral and computational signatures across non-smokers, satiated smokers, and abstinent smokers
